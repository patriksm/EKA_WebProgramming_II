Background ConceptWhat is a WebSocket?

Normally, a browser asks a server for something and the server replies — then the connection closes. This is called HTTP request/response. For a chat app this is useless: we'd have to ask the server every second "any new messages?" — very wasteful.

A WebSocket is a different protocol that starts as HTTP, then upgrades to a persistent two-way channel. Once open, both the browser and server can send messages to each other at any time with very little overhead. Perfect for chat, games, live dashboards, etc.
WebSockets run on top of TCP (the same underlying technology as HTTP). The protocol identifier is ws:// (or wss:// for encrypted).
★

Background ConceptThe WebSocket Handshake

Before sending chat messages, the browser and server must perform a special HTTP upgrade handshake. Here is what happens, step by step:
  1. Browser sends an HTTP GET request with a special header: Upgrade: websocket.
  2. It also sends a random key: Sec-WebSocket-Key: <base64 random>.
  3. The server must take that key, append a magic string, SHA-1 hash it, and base64-encode it.
  4. Server replies with 101 Switching Protocols and returns the computed key.
  5. The connection is now a WebSocket — raw frames flow back and forth.

After the handshake, data is sent as binary frames (not plain text). We have to encode outgoing frames and decode incoming ones manually.

Step 1Create the PHP Server Skeleton

First, we create a TCP socket that listens for connections. PHP's built-in socket_* functions let us work at the raw network level. Think of a socket as a "telephone jack" — we open it, bind it to an address and port, and wait for callers.

Key functions used:
  • socket_create() — Creates a socket resource (like buying a phone).
  • socket_bind() — Ties it to an IP address and port number.
  • socket_listen() — Marks the socket as passive, waiting for connections.
  • socket_select() — Efficiently monitors multiple sockets at once, waking up only when data arrives.
PHP server.php 
<?php
// Tell PHP not to time out — we want this script to run forever
set_time_limit(0);

// HOST and PORT where our WebSocket server will listen
define('HOST', '127.0.0.1');
define('PORT', 8080);

// Create a TCP/IP socket
// AF_INET  = IPv4, SOCK_STREAM = TCP (reliable, ordered), SOL_TCP = TCP protocol
$server = socket_create(AF_INET, SOCK_STREAM, SOL_TCP);

// Allow reusing the port immediately after the server restarts
socket_set_option($server, SOL_SOCKET, SO_REUSEADDR, 1);

// Bind the socket to our chosen host and port
socket_bind($server, HOST, PORT);

// Start listening — allow up to 20 pending connections in the queue
socket_listen($server, 20);

echo "✅ WebSocket server started on ws://" . HOST . ":" . PORT . "\n";
echo "   Waiting for connections...\n";

// $clients holds ALL open socket connections
// We start with just the server socket itself
$clients = [$server];

// $handshakeDone tracks which clients have completed the WebSocket handshake
$handshakeDone = [];

// Main event loop — runs forever, processing events
while (true) {
    // Copy the $clients array — socket_select() modifies it
    $read = $clients;
    $write = null;
    $except = null;

    // socket_select() blocks here until at least one socket has activity
    // It puts only the "active" sockets back into $read
    if (socket_select($read, $write, $except, 0, 10000) === false) {
        break;
    }

    // Loop over every socket that has data waiting
    foreach ($read as $socket) {
        if ($socket === $server) {
            // A NEW client is trying to connect
            $client = socket_accept($server);
            $clients[] = $client;
            echo "🔗 New connection accepted.\n";
        } else {
            // An EXISTING client sent data — we handle it next
            handleClient($socket, $clients, $handshakeDone);
        }
    }
}

socket_close($server);
The while(true) loop is sometimes called an event loop. It is the heart of any server — it just keeps checking for activity and responding to it.

Step 2Implement the WebSocket Handshake

When a browser connects, the first thing it sends is an HTTP GET request with special WebSocket headers. We need to:
  1. Read the raw HTTP request from the socket.
  2. Extract the Sec-WebSocket-Key value.
  3. Compute the acceptance key by hashing it with the WebSocket magic string.
  4. Send back a valid HTTP 101 response.
The magic string (258EAFA5-E914-47DA-95CA-C5AB0DC85B11) is defined in RFC 6455 — the WebSocket specification. It's a fixed UUID used by all WebSocket implementations in the world.
Until the handshake is complete, no WebSocket frames can be sent. If we skip this step, the browser will refuse the connection.
PHP server.php — add below the main loop 
/**
 * Called whenever a client socket has data ready to read.
 * Decides whether to do the handshake or handle a WS frame.
 */
function handleClient($socket, &$clients, &$handshakeDone): void
{
    // Read up to 4096 bytes from the client
    $data = socket_read($socket, 4096);

    if ($data === false || $data === '') {
        // Client disconnected
        removeClient($socket, $clients, $handshakeDone);
        return;
    }

    $id = (int)$socket; // Use socket as a unique ID key

    if (!isset($handshakeDone[$id])) {
        // First message from this client must be the HTTP upgrade request
        doHandshake($socket, $data, $handshakeDone);
    } else {
        // Already handshaked — process as a WebSocket data frame
        processFrame($socket, $data, $clients, $handshakeDone);
    }
}

/**
 * Performs the RFC 6455 WebSocket opening handshake.
 */
function doHandshake($socket, string $request, &$handshakeDone): void
{
    // Extract the Sec-WebSocket-Key from the HTTP headers
    if (!preg_match('/Sec-WebSocket-Key: (.+)\r\n/', $request, $matches)) {
        echo "❌ Not a WebSocket request — closing.\n";
        socket_close($socket);
        return;
    }

    $key = trim($matches[1]);

    // The magic UUID defined in RFC 6455 — every WebSocket server uses this
    $magicString = '258EAFA5-E914-47DA-95CA-C5AB0DC85B11';

    // Compute the acceptance key:
    // 1. Concatenate the client key + magic string
    // 2. SHA-1 hash the result
    // 3. Base64-encode the hash
    $acceptKey = base64_encode(sha1($key . $magicString, true));

    // Build the HTTP 101 response — must include exactly these headers
    $response  = "HTTP/1.1 101 Switching Protocols\r\n";
    $response .= "Upgrade: websocket\r\n";
    $response .= "Connection: Upgrade\r\n";
    $response .= "Sec-WebSocket-Accept: {$acceptKey}\r\n";
    $response .= "\r\n"; // Empty line signals end of HTTP headers

    socket_write($socket, $response);

    // Mark this socket as "handshake done"
    $handshakeDone[(int)$socket] = true;
    echo "🤝 Handshake complete for socket " . (int)$socket . ".\n";
}
The sha1($key . $magicString, true) — the second argument true means "return raw binary bytes", not a hex string. Base64-encoding raw bytes gives the correct result.

Step 3Frame Encoding & Decoding

After the handshake, data travels as WebSocket frames — a compact binary format. Each frame has a small header that describes the data.

Decoding (incoming from browser): The browser always masks its outgoing data using 4 random bytes. We must XOR each byte of the payload with the corresponding masking byte to recover the original message.

Encoding (outgoing from server): The server sends data unmasked. We just need to write a 2-byte (or longer) header describing the payload length.
PHP server.php — add after doHandshake() 
/**
 * Decodes a raw WebSocket frame sent by the browser.
 * Returns the decoded text payload, or false on error.
 */
function decodeFrame(string $data)
{
    // We need at least 6 bytes (2 header + 4 mask)
    if (strlen($data) < 6) return false;

    // Byte 1: FIN bit + opcode
    // opcode 0x1 = text frame, 0x8 = close frame
    // ord() converts a character to its numeric ASCII/byte value
    $opcode = ord($data[0]) & 0x0F;

    if ($opcode === 0x8) {
        return false; // Close frame — signal disconnect
    }

    // Byte 2: MASK flag (bit 7) + payload length (bits 0-6)
    // & 0x7F clears the top bit to get just the 7-bit length
    $length = ord($data[1]) & 0x7F;

    // For simplicity we handle only payloads up to 125 bytes
    // (Larger messages need 2 or 8 more length bytes — see RFC 6455 §5.2)
    if ($length > 125) return false;

    // The 4 masking-key bytes start at byte index 2
    $masks = substr($data, 2, 4);

    // The actual payload starts at byte index 6
    $encoded = substr($data, 6, $length);

    // XOR each payload byte with the corresponding mask byte (cycling through 4 masks)
    // This is the unmasking algorithm from RFC 6455
    $decoded = '';
    for ($i = 0; $i < strlen($encoded); $i++) {
        $decoded .= $encoded[$i] ^ $masks[$i % 4];
    }

    return $decoded;
}

/**
 * Encodes a text string into a WebSocket frame for sending.
 * Server-to-client frames are NOT masked (RFC 6455 §5.1).
 */
function encodeFrame(string $text): string
{
    $length = strlen($text);

    // Byte 1: 0x81 = FIN bit set (1) + opcode 0x1 (text frame)
    // chr() converts a number to the corresponding byte character
    $frame = chr(0x81);

    if ($length <= 125) {
        // Length fits in 7 bits — write it directly as byte 2
        $frame .= chr($length);
    } elseif ($length <= 65535) {
        // 126 signals "next 2 bytes hold the real length" (big-endian)
        $frame .= chr(126) . pack('n', $length);
    }
    // Append the raw text payload (no masking needed from server)
    $frame .= $text;

    return $frame;
}

Step 4Handle Messages & Broadcast to All

When a client sends a chat message, we need to:
  1. Decode the incoming WebSocket frame into a plain string.
  2. Broadcast it to every other connected client by encoding a new frame and writing it to each socket.
  3. Handle disconnections — remove the socket from our list so we don't try writing to a dead connection.
PHP server.php — add after encodeFrame() 
/**
 * Called when a handshaked client sends a WebSocket frame.
 */
function processFrame($socket, string $data, &$clients, &$handshakeDone): void
{
    $message = decodeFrame($data);

    if ($message === false) {
        // Close frame or bad data — remove client
        removeClient($socket, $clients, $handshakeDone);
        return;
    }

    // Trim whitespace and ignore empty messages
    $message = trim($message);
    if ($message === '') return;

    echo "💬 Message received: {$message}\n";

    // Broadcast to all OTHER connected (and handshaked) clients
    broadcast($socket, $message, $clients, $handshakeDone);
}

/**
 * Sends a message to every client except the sender.
 */
function broadcast($sender, string $message, array $clients, array $handshakeDone): void
{
    $frame = encodeFrame($message);

    foreach ($clients as $client) {
        // Skip the server socket itself and the sender
        if (!isset($handshakeDone[(int)$client])) continue;
        if ($client === $sender) continue;

        socket_write($client, $frame);
    }
}

/**
 * Closes and removes a disconnected client from our tracking arrays.
 */
function removeClient($socket, &$clients, &$handshakeDone): void
{
    echo "🔌 Client disconnected: socket " . (int)$socket . "\n";

    socket_close($socket);

    // Remove from the clients list
    $key = array_search($socket, $clients);
    if ($key !== false) unset($clients[$key]);

    // Remove handshake record
    unset($handshakeDone[(int)$socket]);
}
We skip the sender when broadcasting because the JavaScript client will display the message locally immediately after sending — no need to echo it back.

Step 5Build the HTML Chat Client

The browser has a built-in WebSocket API — no libraries needed. Create a connection with new WebSocket('ws://...'), then use these event handlers:
  • ws.onopen — fires when the connection is established.
  • ws.onmessage — fires when a message arrives from the server.
  • ws.onclose — fires when the connection is closed.
  • ws.send(text) — sends a message to the server.

  <script>
    // 1. Create the WebSocket connection to our PHP server
    const ws = new WebSocket('ws://127.0.0.1:8080');

    const log    = document.getElementById('log');
    const status = document.getElementById('status');

    // Helper: append a message line to the chat log
    function addLine(text, cssClass) {
      const div = document.createElement('div');
      div.className = 'msg ' + cssClass;
      div.textContent = text;
      log.appendChild(div);
      // Auto-scroll to the newest message
      log.scrollTop = log.scrollHeight;
    }

    // 2. Connection opened — the handshake succeeded
    ws.onopen = () => {
      status.textContent = '✅ Connected';
      status.style.color = '#1a8f3c';
      addLine('Connected to chat server.', 'sys');
    };

    // 3. Message received from the server
    ws.onmessage = (event) => {
      addLine(event.data, 'theirs');
    };

    // 4. Connection closed
    ws.onclose = () => {
      status.textContent = '❌ Disconnected';
      status.style.color = '#c0392b';
      addLine('Disconnected from server.', 'sys');
    };

    // 5. Send a message when the user clicks Send (or presses Enter)
    function sendMsg() {
      const name = document.getElementById('nameBox').value.trim() || 'Anonymous';
      const text = document.getElementById('msgBox').value.trim();
      if (!text) return;

      // Prepend the username — the server will broadcast exactly this string
      const full = name + ': ' + text;
      ws.send(full);

      // Show own message locally (the server does NOT echo it back)
      addLine(full, 'mine');

      // Clear the input box
      document.getElementById('msgBox').value = '';
    }

    // Allow pressing Enter to send
    document.getElementById('msgBox')
      .addEventListener('keydown', e => { if (e.key === 'Enter') sendMsg(); });
  </script>

Step 6Run & Test Your Chat App

Now let's bring it to life. You need a terminal and a browser.

1. Start the server — open your terminal, navigate to the project folder, and run:

Bash
cd php-chat
php server.php

You should see: ✅ WebSocket server started on ws://127.0.0.1:8080

2. Open two browser tabs — open index.html directly in your browser (just drag the file onto it, or use File → Open). Open a second tab the same way.

3. Chat! — Type a message in one tab and click Send. It should appear in the other tab. Watch your terminal — you'll see the handshake and message logs.

Do NOT open index.html via a web server on a different port or origin — browsers may block the WebSocket for security reasons (CORS). Opening as a local file works fine for this exercise.
To stop the server, press Ctrl + C in the terminal.
